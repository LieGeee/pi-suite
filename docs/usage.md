# pi-gui 桌面版使用指南

本文档介绍 pi-gui 桌面版的日常使用：斜杠命令、快捷键、图片粘贴、手机版配对。

---

## 一、斜杠命令（在输入框输入 `/` 触发）

在输入框中输入 `/` 会弹出斜杠命令菜单，可用方向键选择、回车发送。

### 界面操作（Host 命令）

| 命令 | 作用 | 提交方式 |
|------|------|----------|
| `/model` | 为当前会话选择模型（提供商 + 模型） | 弹出选项 |
| `/thinking` | 设置当前会话推理强度（低 / 中 / 高 / 超高） | 弹出选项 |
| `/tree` | 浏览并跳转当前会话的分支（会话树） | 立即执行 |
| `/status` | 在时间线中显示当前会话的覆盖状态 | 立即执行 |
| `/session` | 在时间线中显示当前会话详情 | 立即执行 |
| `/name 新标题` | 重命名当前会话 | 预填模板 |
| `/compact` | 立即压缩当前会话上下文 | 立即执行 |
| `/reload` | 重新加载提示词、技能和会话资源 | 立即执行 |
| `/login` | 为当前工作区认证提供商 | 弹出选项 |
| `/logout` | 移除当前工作区的提供商登录 | 弹出选项 |
| `/settings` | 打开模型、技能和通知设置 | 立即执行 |
| `/scoped-models` | 选择哪些模型出现在模型选择器中 | 立即执行 |

### 运行时命令（来自技能/扩展）

启用技能后，每个技能会注册自己的斜杠命令（如 `/skill:xxx`），在斜杠菜单的「运行时命令」分区中显示。技能命令是否出现在菜单中，受设置中的「技能命令开关」控制。

> 💡 也可以在 `/compact`、`/name` 等命令后追加补充说明，例如 `/name 需求评审`、`/compact 只保留关键决策`。

## 二、键盘快捷键

| 快捷键 (Windows) | 快捷键 (macOS) | 作用 |
|------------------|----------------|------|
| `Ctrl + ,` | `⌘ + ,` | 打开设置 |
| `Ctrl + J` | `⌘ + J` | 打开/关闭终端面板 |
| `Ctrl + B` | `⌘ + B` | 切换侧边栏 |
| `Ctrl + D` | `⌘ + D` | 打开/关闭变更（Diff）面板 |
| `Ctrl + Shift + O` | `⌘ + Shift + O` | 新建对话 |
| `Ctrl + F` | `⌘ + F` | 在当前会话时间线中搜索 |
| `Ctrl + V` | `⌘ + V` | 粘贴剪贴板中的图片到输入框 |

> 终端面板内也有专属快捷键：当焦点在终端内时，`Ctrl+J` 仍可开关终端面板。

## 三、粘贴图片

pi-gui 支持**直接粘贴剪贴板图片**到对话输入框，无需保存文件：

### 方式一：快捷键粘贴
1. 复制任意图片（截图工具、浏览器右键复制图片等）
2. 焦点放在对话输入框中
3. 按 **`Ctrl + V`**（macOS 为 `⌘ + V`）——注意不是普通的粘贴文本，而是读取剪贴板图片

### 方式二：直接粘贴
在输入框中直接按 `Ctrl + V` 粘贴剪贴板中的图片，会自动作为图片附件插入。

### 支持的图片格式

| 格式 | MIME |
|------|------|
| PNG | image/png |
| JPG / JPEG | image/jpeg |
| GIF | image/gif |
| WebP | image/webp |

> ⚠️ 单张图片最大 **10 MB**。超出会被省略/拒绝。

### 附件的其他方式
- 输入框下方会显示已添加的图片附件，可逐个移除
- 图片随消息一起发送给模型，用于多模态理解

## 四、手机版配对（桌面 ↔ 手机同步）

手机版（Android APK / H5）通过 relay 服务与桌面端同步，架构如下：

```text
pi-gui desktop <--WebSocket--> pi-mobile-relay <--WebSocket/HTTPS--> mobile (uni-app)
```

### 配对步骤
1. 启动 relay 服务（见 `mobile/relay/README.md`），确保手机和电脑在同一网络
2. 桌面端打开「设置 → 手机同步」，设置 relay 地址和配对 Token
3. 手机端打开 App → 设置页，填写：
   - **服务器地址**：relay 地址（如 `ws://192.168.x.x:8787/ws/mobile`）
   - **Token**：桌面端生成的配对 Token（可在手机端生成后复制到 Windows 端，或扫描二维码）
4. 连接成功后，手机端可查看任务/对话列表、通知，并发送授权指令

### 手机端功能（uni-app）
- **对话**：查看桌面端任务/对话列表，按状态筛选（全部/最近/未读/失败）
- **通知**：接收桌面端通知推送
- **设置**：relay 地址与 Token 管理、配对状态查看

> 手机端不存储模型密钥或 Pi 认证文件，所有请求通过配对 Token 授权转发到桌面端执行。
