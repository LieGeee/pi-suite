# 斜杠命令速查

在 pi-gui 对话输入框中输入 `/` 会弹出斜杠命令菜单，支持方向键选择、回车发送。

## 界面操作命令（Host）

| 命令 | 作用 | 提交方式 |
|------|------|----------|
| `/model` | 为当前会话选择模型（提供商 + 模型） | 弹出选项 |
| `/thinking` | 设置当前会话推理强度：低 / 中 / 高 / 超高 | 弹出选项 |
| `/tree` | 浏览并跳转当前会话的分支（会话树） | 立即执行 |
| `/status` | 在时间线中显示当前会话的覆盖状态 | 立即执行 |
| `/session` | 在时间线中显示当前会话详情 | 立即执行 |
| `/name 新标题` | 重命名当前会话 | 预填模板 |
| `/compact` | 立即压缩当前会话上下文 | 立即执行 |
| `/reload` | 重新加载提示词、技能和会话资源 | 立即执行 |
| `/login` | 为当前工作区认证提供商 | 弹出选项 |
| `/logout` | 移除当前工作区的提供商登录 | 弹出选项 |
| `/settings` | 打开模型、技能和通知设置 | 立即执行 |
| `/scoped-models` | 选择哪些模型出现在模型选择器中 | 立即执行 |

## 推理强度取值

| 值 | 说明 |
|----|------|
| `low` | 低：响应更快，推理较轻 |
| `medium` | 中：兼顾速度与深度，适合日常任务 |
| `high` | 高：为复杂问题提供更强推理能力 |
| `xhigh` | 超高：提供最高级别推理深度 |

## 运行时命令（技能/扩展）

启用技能后，每个技能可注册自己的斜杠命令（如 `/skill:xxx`），显示在斜杠菜单的「运行时命令」分区。

- 技能命令是否出现在菜单中，受设置中的**技能命令开关**控制。
- 命令来源可能是技能（skill）或其他扩展，来源会以标签形式标注。

## 补充说明

- `/name` 和 `/compact` 可带参数：`/name 需求评审`、`/compact 只保留关键决策`
- 若命令不完整（如单独发 `/model`），会提示先在斜杠菜单选择，例如：「先在斜杠菜单里选择提供商和模型，再发送 /model」
- 输入 `/` 后继续输入关键字可过滤匹配命令

## 相关快捷键

| 快捷键 (Win) | 快捷键 (macOS) | 作用 |
|--------------|----------------|------|
| `Ctrl + ,` | `⌘ + ,` | 打开设置 |
| `Ctrl + Shift + O` | `⌘ + Shift + O` | 新建对话 |
| `Ctrl + F` | `⌘ + F` | 时间线搜索 |
